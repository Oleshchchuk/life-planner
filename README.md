## Идея

Планы появляются в разговоре: купить продукты, закончить проект, записаться к врачу.
Агент с доступом к локальным данным превращает их в задачи, списки и напоминания.
Виджет на рабочем столе показывает актуальный план и позволяет отмечать выполненное.

```text
Сообщение в чате → Агент → Локальные данные ⇄ Виджет Ubuntu
```

Приложение должно работать самостоятельно: показывать дела и напоминать о них,
даже когда чат закрыт. Отдельный сервер и встроенный AI API для этого не нужны.

## Один планировщик, три режима

| Режим | Что перед глазами |
| --- | --- |
| **Mini** | Вода, количество задач, ближайшее напоминание |
| **Medium** | Сегодня, завтра, быстрые отметки выполнения |
| **Full** | Проекты, списки покупок и план на неделю |

Окно можно будет полностью скрыть, сохранив работу напоминаний.
Первая оболочка задумана в духе Winamp и pixel art. Темы смогут менять внешний вид
и компоновку, сохраняя общие данные и логику.

## Данные остаются локальными

Репозиторий предназначен для исходного кода и документации.
Личные дела, базы данных, резервные копии и секреты сюда не входят.
Точный путь хранения и способ изменения данных будут зафиксированы при реализации.
